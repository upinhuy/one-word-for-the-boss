## The word

**Hovercraft** — the boss who hovers over every shoulder.

It is funny on its own, it rings true of micromanagers everywhere, and it
travels: it works for a boss in an office, a kitchen, or a warehouse without
needing an explanation. One word, ten characters, no caption required.

## How it works

`main.ts` (Node 22, standard library only) writes exactly one word to
`/output/entry.txt`:

```
Hovercraft
```

Run it locally:

```sh
node main.ts
```
